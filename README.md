# PdM Strategy Training

PdMの「戦略立案」「優先順位づけ」「ステークホルダーとの合意形成」を鍛えるための、
個人用ケーススタディ道場。ビルド不要・バックエンドなしの静的Webアプリで、
記録はすべてブラウザのlocalStorageに保存される(他人と共有されない)。

## 使い方

`index.html` を直接ブラウザで開くか、GitHub Pagesのリンクを開くだけ。

1. 「ケース一覧」から架空のPdMケースを選ぶ
2. ①診断 ②基本方針 ③優先順位の結論 ④一番手強い相手への説明、の4項目に回答する
3. 5つの評価軸(診断・方針・優先順位・数字・合意形成)で自己採点する
4. 「ダッシュボード」で初回と直近のスコアを比較し、伸びた軸・停滞している軸を確認する

## 評価軸(共通ルーブリック)

すべてのケースで同じ5軸を使う。ケースごとの知識ではなく、転用可能な思考の型を鍛える。

- 診断の具体性
- 方針のトレードオフ明示
- 優先順位とリソース制約の整合
- 数字の正確性・検算
- ステークホルダー別の合意形成

`rubric.js` に各軸のレベル1〜5の判定基準がある。

## ケースを追加する

`cases.js` の `CASES` 配列に、同じ形式でシナリオを追記するだけ。

## 構成

- `index.html` / `style.css` — 画面
- `rubric.js` — 評価軸の定義
- `cases.js` — ケースシナリオ + 初期シード(実際のコーチングセッションの記録)
- `app.js` — ルーティング・保存・レーダーチャート/推移グラフの描画
